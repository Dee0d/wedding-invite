# Свадебное приглашение — Кирилл & Елизавета 💚

Сайт-приглашение на свадьбу **28 ноября 2026, Курск, Киевская 69, ивент-пространство «Вместе»**.

Выполнен в пастельной зелёной палитре с большой анимированной графикой: падающие
лепестки и искры на canvas, плавные градиентные пятна, вращающиеся кольца монограммы,
обратный отсчёт, конфетти при отправке ответа, появление блоков при прокрутке,
бегущая лента и многое другое. При этом всё уважает системную настройку
«уменьшить движение» (`prefers-reduced-motion`).

## Что внутри

| Раздел | Описание |
| --- | --- |
| `/` | Приглашение: hero с монограммой, обратный отсчёт, детали, программа дня, место, анкета гостя |
| `/responses` | Все полученные ответы: статистика, топ напитков и аллергий, CSV/копирование |
| `/api/rsvp` | Приём ответа → запись в Google-таблицу + бэкап в PostgreSQL |
| `/api/stats` | Публичная агрегированная статистика |
| `/api/responses` | Список ответов в JSON (ключ `?key=`, если задан `ADMIN_TOKEN`) |
| `/setup` | Пошаговая настройка подключения Google-таблицы без правки файлов |
| `/api/settings` | Сохранение URL веб-приложения Apps Script в базе |
| `/api/sync` | Досылка в таблицу всех ранее сохранённых ответов |

## Вопросы анкеты (как просили)

1. **Имя и фамилия** гостя.
2. **Придёт ли гость вообще** — «Обязательно приду» / «К сожалению, нет».
3. **Напитки** — алкогольные и безалкогольные чекбоксами + поле «свой вариант»
   (показываются только тем, кто придёт).
4. **Аллергии и пищевые предпочтения** — готовые чипсы (орехи, лактоза, глютен,
   цитрусовые, мёд, морепродукты, яйца, ягоды, веган) + свободное уточнение.
5. Бонусом: **+1 гость** и **пожелания/комментарий**.

Дресс-кода нет — об этом сказано отдельным блоком с палитрой «для вдохновения»
(подсказка, а не правило).

## Подключение Google-таблицы

Приложение отправляет готовую строку в таблицу через **Google Apps Script**
(веб-приложение). Это не требует серверных ключей и работает с любой таблицей,
к которой у скрипта есть доступ.

> **Самый простой путь — ничего не читать:** откройте на сайте страницу
> **`/setup`**. Там те же 4 шага, готовый код с кнопкой «Скопировать» и поле,
> куда вставить полученную ссылку. Сохранится сразу, без правки файлов и
> перезапуска сервера.

### Вариант А. Через страницу /setup (рекомендуется)

1. Откройте `https://ваш-сайт/setup`
2. Выполните 4 шага из инструкции на странице (код уже готов к копированию)
3. Вставьте ссылку `/exec` в поле и нажмите «Сохранить»
4. Отправьте тестовый ответ на главной — строка появится в таблице за пару секунд

### Вариант Б. Через переменную окружения

Задайте `GOOGLE_SHEET_WEBAPP_URL` в `.env` (см. `.env.example`) и перезапустите
приложение. Переменная имеет приоритет над значением из базы.

### Если ответы уже были отправлены до подключения

На странице `/responses` есть кнопка **«Дослать ответы в таблицу»** — она
повторит отправку всех сохранённых анкет.

### Код скрипта (для справки)

1. Откройте таблицу:
   <https://docs.google.com/spreadsheets/d/1WCVJwD-6lRwfQminRV_yWIPxm_rTAmMjWr2oNnr3Pn4/edit>
2. Меню **Расширения → Apps Script** и вставьте код:

```javascript
// Заголовки столбцов, которые создастся при первой записи
var HEADERS = [
  'Дата ответа', 'Имя и фамилия', 'Присутствие', 'Напитки',
  'Аллергии и предпочтения', '+1 гость', 'Комментарий'
];

function doPost(e) {
  try {
    var payload = JSON.parse(e.postData.contents);
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];

    // создаём шапку, если её ещё нет
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(payload.headers || HEADERS);
      sheet.getRange(1, 1, 1, sheet.getLastColumn()).setFontWeight('bold');
    }

    // пишем готовый ответ
    sheet.appendRow(payload.values);

    return ContentService
      .createTextOutput(JSON.stringify({ result: 'success' }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService
      .createTextOutput(JSON.stringify({ result: 'error', message: String(err) }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

// проверка вручную из редактора: убедитесь, что строка появилась в таблице
function testAppend() {
  doPost({
    postData: {
      contents: JSON.stringify({
        headers: HEADERS,
        values: [new Date().toISOString(), 'Проверка', 'Приду', 'Шампанское', 'Аллергии нет', 'Нет', '—']
      })
    }
  });
}
```

3. **Начать развёртывание → Веб-приложение**:
   - *Execute as*: **Me**
   - *Who has access*: **Anyone**
4. Скопируйте URL вида `https://script.google.com/macros/s/.../exec`.
5. Пропишите его в `.env` (см. `.env.example`) и перезапустите приложение:

```bash
GOOGLE_SHEET_WEBAPP_URL=https://script.google.com/macros/s/XXXXXXXX/exec npm run start
```

После этого каждый отправленный ответ будет сразу дописываться в таблицу, а в
анкете гость увидит подтверждение «Ответ добавлен в Google-таблицу».

> Если переменная не задана — ничего не ломается: ответ сохраняется в PostgreSQL
> и остаётся на странице `/responses`, откуда его можно скопировать в таблицу
> одной кнопкой («Скопировать для таблицы») или выгрузить CSV.

## Запуск

```bash
npm install
npx drizzle-kit push      # создать таблицу rsvp_responses
npm run build
npm run start             # http://localhost:3000
```

База данных: PostgreSQL, подключение через `DATABASE_URL` в `.env`.

## Защита страницы ответов

По умолчанию `/responses` открыта всем. Чтобы закрыть её, задайте в `.env`:

```bash
ADMIN_TOKEN=ваш-секретный-ключ
```

После этого страница будет доступна только по адресу
`/responses?key=ваш-секретный-ключ`.

## Как поменять тексты/время

Все данные торжества собраны в одном файле — `src/lib/wedding.ts`:
имена, дата, адрес, список напитков, чипсы аллергий и программа дня.
Время начала (`dateISO`) задаёт и обратный отсчёт.
