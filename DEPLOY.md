# Как поставить сайт «навсегда» (за 15 минут)

## Почему текущая ссылка не подходит для свадьбы

Сайт сейчас работает внутри **временной песочницы разработки**. Я проверил изнутри:

- идентификатор песочницы меняется при каждой пересборке (`E2B_SANDBOX_ID`),
- время работы сбрасывается (`/proc/uptime` показывал 77 секунд),
- внутри нет ключа доступа к API песочницы, чтобы продлить её жизнь.

Технически продлить её на 45 дней **невозможно** — это окружение для разработки,
его выключает платформа, а не приложение. Рассчитывать на него до 28 ноября нельзя.

**Хорошая новость:** файлы и база данных при этом не теряются — я проверял,
созданные ранее файлы и таблицы на месте. И главное: после настройки
Google-таблицы все ответы гостей будут храниться в вашей таблице, то есть
вне этого сайта. Так что даже если сайт отключится, собранные ответы останутся.

---

## План: переехать на постоянный хостинг

Нужны две бесплатные вещи: **место для сайта** и **база данных**.

### Шаг 1. Скачайте архив с сайтом

Откройте в браузере:

```
https://<ваш-текущий-адрес>/svadba-istochniki.tar.gz
```

Сохраните файл к себе на компьютер. Внутри — весь код сайта (56 файлов).

### Шаг 2. Создайте базу данных (бесплатно)

Зайдите на **https://neon.tech** → Sign up (можно через Google) → Create project.

После создания Neon покажет строку подключения, вида:

```
postgresql://user:password@ep-xxx.eu-central-1.aws.neon.tech/dbname?sslmode=require
```

**Скопируйте её** — понадобится на шаге 4.

> Альтернатива: https://supabase.com → Project Settings → Database → Connection string.

### Шаг 3. Залейте сайт на хостинг

Зайдите на **https://vercel.com** → Sign up (через GitHub или email).

1. Нажмите **Add New… → Project**
2. Выберите **Import Git Repository** → если репозитория нет, используйте
   **Deploy from local folder** через Vercel CLI, либо просто загрузите папку
   с распакованным архивом перетаскиванием
3. Vercel сам определит Next.js — настройки менять не нужно

### Шаг 4. Пропишите переменные окружения

В настройках проекта Vercel → **Settings → Environment Variables** добавьте:

| Имя | Значение |
|---|---|
| `DATABASE_URL` | строка подключения из шага 2 |
| `GOOGLE_SHEET_WEBAPP_URL` | ссылка `/exec` из страницы `/setup` (если уже получали) |

### Шаг 5. Создайте таблицы в базе

Один раз, на вашем компьютере, в папке с сайтом:

```bash
npm install
DATABASE_URL="ваша-строка-из-шага-2" npx drizzle-kit push
```

### Шаг 6. Настройте Google-таблицу

Откройте `https://ваш-новый-адрес/setup` и пройдите 4 шага — те же, что и раньше.
Ссылка `/exec` вставится уже туда.

## Если Vercel недоступен (оплата/регистрация)

Подойдёт любой российский хостинг с Node.js и PostgreSQL:

- **Timeweb Cloud** — тариф «Node.js» + managed PostgreSQL
- **Reg.ru** — хостинг с поддержкой Node.js
- **Selectel** — облачный сервер

При переносе меняются только шаги 3–5, остальное identчно.

---

## Что делать, если совсем нет времени на хостинг

Минимум, который обязательно нужно сделать **до рассылки приглашений**:

1. Открыть `/setup` и подключить Google-таблицу — тогда ответы гостей будут
   сохраняться в таблицу даже без работающего сайта.
2. Скачать архив `svadba-istochniki.tar.gz` — чтобы не потерять готовый сайт.

Всё остальное можно доделать позже.
